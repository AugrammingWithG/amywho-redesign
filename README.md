# Amy Who? Digital: redesign concept

A concept mockup by **Cre8tive Sync** for [Amy Who? Digital](https://www.amywho.com.au/) (Adelaide). This is not Amy's live website.

- **Website concept:** `/` is an interactive, living-3D redesign. Her stripe motif becomes a real-time 3D supergraphic that re-forms into each service, with PitchPoint motion and GSAP ScrollTrigger transitions.
- **Social posts:** `/social/` has two 1080×1350 Instagram loops in Amy's current brand guide (MP4 + cover PNG in `/social/export/`).

Static HTML/CSS/JS. Three.js 0.169 and GSAP 3.12.5 load from pinned CDNs. There is no build step. Search engines are asked not to index it (`noindex` + `robots.txt`).

Photos, logo and case-study facts belong to Amy Who? Digital and are used here only to present the concept.
